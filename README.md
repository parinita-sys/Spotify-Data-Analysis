
# 🎵 Spotify Data Analysis

## About the Project
This project explores Spotify track data using Python to understand music characteristics and identify patterns through exploratory data analysis (EDA).

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
The dataset contains information about Spotify tracks, including popularity, energy, danceability, tempo, artists, and genres.

## Analysis Performed
- Explored the dataset and its columns
- Examined summary statistics
- Analysed track characteristics
- Created visualizations to explore patterns in the data

## Key Learnings
- Data exploration and analysis using Pandas
- Data visualization
- Interpreting patterns in a real-world dataset

## Project Structure
- `analysis.py` — Python analysis script
- `dataset.csv` — Dataset used for the analysis
